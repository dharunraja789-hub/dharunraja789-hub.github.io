Files:

- DharunResume.pdf: resume PDF backup

Publish with GitHub Pages:
1. Sign in to GitHub and create a PUBLIC repository named exactly:
   dharunraja789-hub.github.io
2. Upload index.html and DharunResume.pdf from this folder to the repository root.
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select branch main and folder /(root), then Save.
6. Wait for deployment. Your expected URL is:
   https://dharunraja789-hub.github.io/

Note: The website HTML appears to contain its own embedded resume preview data, so the website may work without the separate PDF. The PDF is included as a backup asset. Review contact details and any future-dated experience before publishing publicly.
